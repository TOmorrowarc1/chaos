# Rules

1. Never change any code unless the user explicitly uses "apply" or "rewrite" as the command verb.
   - "apply" means implement a specific change the user describes
   - "rewrite" means replace the content of a file the user specifies
   - Any other phrasing is discussion/planning only
2. Read-only exploration is always allowed.
3. When asked to analyze or explain, do not write or modify code.
4. After every modification to any source file, append an entry to context/record.md with the current time and a concise, precise description of what was changed.
